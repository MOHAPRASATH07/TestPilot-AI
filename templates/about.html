Evaluation Metrics
Formulas
1. Average Percentage of Faults Detected (APFD)

Standard metric evaluating how early tests discover faults, assuming uniform execution duration:

$$\text{APFD} = 1 - \frac{\sum_{i=1}^{m} r_i}{n \times m} + \frac{1}{2n}$$
  • \(n\): Total number of test cases in the suite
  • \(m\): Total number of distinct faults exposed by the test suite
  • \(r_i\): Position (rank) of the first test that reveals fault \(i\)
2. Cost-Cognizant APFD (APFDc)

Evaluates fault discovery per unit of test execution time (accounting for non-uniform durations):

$$\text{APFDc} = \frac{\sum_{i=1}^{m} \left( \sum_{j=r_i}^{n} d_j - \frac{1}{2} d_{r_i} \right)}{\sum_{i=1}^{n} d_i \times m}$$
  • \(d_i\): Execution duration of the test at rank \(i\)
  • Penalizes long-running tests that detect faults late
3. Value-Density Prioritization Function

Balances predicted failure probability against test duration penalty with sensitivity \(\alpha\):

$$\text{Score}(t) = \frac{P(\text{fail} \mid \mathbf{x}_t)}{(\text{duration}_t)^\alpha}$$
Key Empirical Findings
Held-Out Summary
  • Cost-Aware ML delivers +38.0% gain: XGBoost Value-Density achieves an APFDc of 0.7351 compared to 0.5326 for Random ordering.
  • Pure Risk fails cost-awareness: Ordering strictly by \(P(\text{fail})\) yields APFDc of 0.5443 because it front-loads slow flaky tests that consume the testing budget prematurely.
  • Fastest-First is a strong baseline: Fastest-First achieves 0.7390 APFDc due to rapid execution throughput, but ML Value-Density achieves higher early failure recall on tight budgets.
  • Strict Zero-Data Leakage: Evaluated on 12 strictly held-out chronologically later builds with feature scaling fit exclusively on training splits.
